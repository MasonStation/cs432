\doxysubsection{Detailed Description}
Main AST node structure. 

Provides some basic definitions used across many nodes, such as source code info and attribute management. Storage of type-\/specific node data is managed using a tagged union of the other \texorpdfstring{$\ast$}{*}\+Node structures declared earlier in this file.

AST nodes are designed to be semi-\/mutable even after parsing by means of the {\ttfamily attributes} key-\/value mapping that is stored in every node. List of potential attributes (not exhaustive, and most are irrelevant to Project 2)\+:

Node structures must be explicitly freed using \doxylink{ast_8h_a4a26fe87ac8120a6e15a59792ea68f0f}{ASTNode\+\_\+free}.
