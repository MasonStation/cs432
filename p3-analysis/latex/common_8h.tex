Throw an exception with an error message using {\ttfamily printf} syntax. 

This function uses the {\ttfamily longjmp} functionality in the standard C library to implement exception handling for the lexing and parsing phases. The code that might throw an exception must be wrapped in a {\ttfamily setjmp} block.

Because this function must have access to the {\ttfamily jmp\+\_\+buf} used to connect the {\ttfamily setjmp} callsite with the {\ttfamily longjmp}, this function must be implemented in the compiler or test driver (where the {\ttfamily setjmp} call will be) in other to avoid having an {\ttfamily extern} static variable. Thus, there is no implementation in {\ttfamily common.\+c}, and it is only declared here so that it can be called in the various front end phases of compilation.

Throw an exception with an error message using {\ttfamily printf} syntax.
